# Мапа, маршрути та атрибуція Drive2U

## Мапа

Android/Expo використовує Leaflet 1.9.4 у react-native-webview та стандартні онлайн-тайли OpenStreetMap. Ключ API не потрібен. Мапу можна пересувати й масштабувати за межами Львова; показуються дороги, вулиці й населені пункти. Тап обирає точку, обидва маркери видно одночасно, після побудови маршруту мапа охоплює його геометрію. Якщо тайли не завантажилися, інтерфейс показує повідомлення, а вибір відомих місць лишається доступним.

Атрибуція «© OpenStreetMap contributors» є на мапі. URL тайлів — https://tile.openstreetmap.org/{z}/{x}/{y}.png. WebView передає стабільний User-Agent Drive2U/1.0; звичайний HTTP-кеш WebView не вимикається. Публічні сервери OSM працюють best-effort, без SLA; заборонені bulk/offline prefetch. Перед великим навантаженням потрібен власний або контрактний постачальник тайлів. Умови: https://operations.osmfoundation.org/policies/tiles/ . Leaflet має BSD-2-Clause; ліцензія в mobile/LICENSE.leaflet.txt.

## Маршрути

Мапа і маршрутизатор незалежні. Серверний Demo підтримує лише три синтетичні пари: вокзал ↔ Опера (3,2 км), Опера ↔ університет (1,1 км), вокзал ↔ університет (4,3 км). Це не навігаційні дані. Довільний дорожній маршрут і відстань можливі тільки через налаштований OSRM-compatible Route API. Для цього задайте Routing__OsrmBaseUrl на власний або контрактний HTTPS endpoint; за потреби Routing__Attribution для назви джерела. Ключ залежить від вибраного оператора OSRM і не включений у репозиторій.

Пасажир не вибирає режим провайдера: клієнт спочатку запитує дорожній маршрут. Якщо сервіс не налаштований або маршрут не знайдений, ціна не з'являється; застосунок пропонує явний демонстраційний маршрут вокзал → Опера. Підміни довільного маршруту, прямої лінії або клієнтського розрахунку ціни немає.

## Тестовий тариф

Серверний fixture вокзал → Опера має 3,2 км. Новий Development тариф 50 грн + 42 грн/км дає 184,40 грн через decimal FareCalculator із округленням до двох знаків. Це тестовий тариф, не чинний тариф перевізника. На існуючій SQLite БД повторний seed старе значення не замінює. Зупиніть API, зробіть резервну копію БД і виконайте python server/scripts/update-demo-tariff.py. Скрипт додає нову версію тарифу; попередні пропозиції, поїздки, користувачі й історія не змінюються.
