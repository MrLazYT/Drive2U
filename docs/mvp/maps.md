# Мапи та маршрути Drive2U

Для Android обрано Leaflet 1.9.4 у react-native-webview: бібліотека підтримується
Expo Go, не потребує Google Maps key й дозволяє локальну підкладку. Leaflet JS/CSS
пакуються в застосунок; завантаження CDN не потрібне. Це вибір реалізації MVP,
не зміна вже прийнятого постачальницького ADR (конкретного провайдера раніше
не було погоджено).

## Режими

- **Demo**: локальна схематична мапа Львова й серверні фіксовані маршрути між
  відомими місцями. Геометрія багатоточкова, дистанції/час синтетичні. UI явно
  показує, що дані демонстраційні; вони не призначені для дорожньої навігації.
  Довільні точки поза переліком підтриманих маршрутів не отримують вигаданий quote.
- **Live**: серверний OSRM-сумісний Route API повертає дорожню відстань, час та
  GeoJSON. Endpoint надає оператор: власний сервер або провайдер із відповідними
  умовами. Власні ключі, ліміти та SLA не припускаються. Timeout/недоступність
  відображаються як помилка; ніякого прихованого Demo fallback.

Клієнт передає лише точки й вибраний режим. Сервер контролює відстань і використовує
наявний decimal FareCalculator. Quote зберігає route/tariff snapshot, а Ride фіксує
його після підтвердження. Відстань або ціна від клієнта не приймаються.

Схематичний фон є локальним демонстраційним матеріалом Drive2U, не копією
публічних тайлів і не доказом live картографічної точності. Видима атрибуція
маршруту зберігається в route та UI. Leaflet ліцензується BSD-2-Clause;
bundled package зберігає copyright/license notice.

## Опційні tiles й адреси

Без окремої конфігурації застосунок не звертається до публічного tile server.
Підключення tile URL потребує коректної видимої атрибуції, квот, HTTP cache,
ідентифікації клієнта й дозволу провайдера для WebView. Зокрема публічний
tile.openstreetmap.org має best-effort доступ без SLA, заборону bulk/offline
prefetch, вимоги User-Agent/Referer та caching. Не використовуйте його без
перевірки дотримання всіх умов. Використовуйте власний або погоджений сервіс.

Текстовий фільтр відомих місць працює локально зі списком API. Live geocoding
навмисно не підключений без провайдера з відповідними умовами. GPS, якщо
користувач надає дозвіл, лише допомагає ручному вибору; фонового tracking немає.
